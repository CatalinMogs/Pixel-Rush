# Pixel Rush

A 2D runner game, this game was made with the help of a tutorial on YouTube.

Link: https://www.youtube.com/watch?v=AY9MnQ4x3zk&pp=ygUdcHlnYW1lIHR1dG9yaWFsIGZvciBiZWdpbm5lcnM%3D

## Features

<ul>
  <li>A character running.</li>
  <li>Obstacles known as snail and fly.</li>
  <li>Collect coins</li>
  <li>High Score</li>
</ul>

## How to play it?

The game controls are simple, just press Space to start the game and get into jumping!
